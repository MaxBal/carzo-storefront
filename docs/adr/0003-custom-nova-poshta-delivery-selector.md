# Собственный выбор точки доставки Новой почты

Интерфейс оформления использует собственные поля поиска города и отделения или почтомата, оформленные в стиле сайта, вместо встраивания готового виджета Новой почты. Next.js обращается к официальному справочнику на сервере, не раскрывая ключ API браузеру, а Directus не копирует и не обслуживает этот справочник. В заказ сохраняются устойчивые идентификаторы выбранных сущностей вместе со снимком отображаемого названия, адреса и типа, чтобы исторические данные заказа не менялись вслед за внешним справочником. При недоступности API ранее подтверждённый выбор сохраняется, но произвольный ручной ввод не разрешается; новый выбор требует успешной загрузки справочника. Доступность почтоматов и типов отделений определяется по управляемым в Directus транспортным габаритам и весу упаковки всех товаров корзины; размеры самого изделия для этого не используются. В первой версии почтоматы предлагаются только для одной товарной единицы с валидным профилем отправления; корзина из двух или более единиц использует подходящие отделения до появления достоверного расчёта совместной упаковки.
