# Централизованный выбор товарного контента

Товарная страница будет получать разрешённый контент страницы через один чистый интерфейс `resolveProductContent(params)`, который принимает текущую товарную конфигурацию и возвращает готовые данные галереи, модальных окон наполнения, фиксации и логотипа, а также нижнего rich content. Правила контентной матрицы, резервные значения и предупреждения о пропущенных специализированных материалах остаются внутри этого модуля. Компоненты отображают подготовленные данные и не выполняют собственный выбор. Глобальный контент пяти преимуществ доступен отдельно через `getBenefitModalContent(type)`. Это сохраняет URL источником выбранной конфигурации, локализует будущую интеграцию CMS и позволяет проверять всю матрицу через один публичный интерфейс вместо набора связанных селекторов.
